Cinema project — coordination
=============================

STACK (agreed)
--------------
- Backend: Flask (Python), structured like the lab app (create_app + blueprints)
- Database: SQLAlchemy (cinema/model.py)
- SQLite for local development, the lab MariaDB for the final submission

HTML RULES (Amiga HTML)
-----------------------
- Every page extends base.html: {% extends "base.html" %}
- Put style.css, images and JS inside cinema/static/.
- Link static files with url_for (NOT a plain href):
      <link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
- Links between pages: url_for('<blueprint>.<function>')
      Home           -> {{ url_for('main.index') }}
      Movie X        -> {{ url_for('main.movie_detail', movie_id=movie.id) }}
      Book showtime  -> {{ url_for('main.booking', showtime_id=s.id) }}
      My bookings    -> {{ url_for('main.my_bookings') }}
      Log in         -> {{ url_for('auth.login') }}
      Register       -> {{ url_for('auth.register') }}
      Log out        -> {{ url_for('auth.logout') }}
      Manage movies  -> {{ url_for('admin.manage_movies') }}
      (same for admin.manage_showtimes and admin.manage_food)
- Data each template receives (SQLAlchemy objects, not dicts):
      main/index.html            -> movies           (list of Movie)
      main/movie_detail.html     -> movie            (Movie; use movie.showtimes)
      main/booking.html          -> showtime, food, price_per_seat
      main/my_bookings.html      -> bookings         (list of Booking)
      admin/manage_movies.html   -> movies
      admin/manage_showtimes.html-> showtimes
      admin/manage_food.html     -> food
- Logged-in user in templates: session.user (keys: id, email, is_admin)

DATABASE (cinema/model.py — Amigo BD)
-------------------------------------
Models:
    Movie       (id, title, synopsis, duration, age_rating, poster, genre)
                 poster = path inside static/, e.g. "posters/dune2.jpeg"
    Screen      (id, name, capacity)
    Showtime    (id, movie_id, screen_id, date, time)
    User        (id, email, password_hash, role=UserRole)
    UserRole    enum (customer, management_staff)
    Booking     (id, user_id, showtime_id, num_seats, total_price, booking_date)
    FoodItem    (id, name, description, price, available)
    Package     (id, name, description, ticket_quantity, price)
    PackageItem (package_id, food_item_id, quantity)
    BookingItem (booking_id, food_item_id, quantity, price)
    BookingPackage (booking_id, package_id, quantity, price)
    TicketPrice (day_of_week, price)

In the blueprints, import the models from the package:
    from . import db
    from .model import Movie, Showtime
    db.session.scalars(db.select(Movie)).all()
    db.session.get(Movie, movie_id)
    db.session.add(obj); db.session.commit()

HOW TO RUN
----------
See README.md. Short version (with the venv active and a .env file):
    pip install -r requirements.txt
    flask --app=cinema init-db
    flask --debug --app=cinema run
    open http://127.0.0.1:5000
