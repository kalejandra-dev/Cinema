HTML RULES (Amiga HTML)
-----------------------
- Put every .html inside templates/.
- Put style.css, images, JS inside static/.
- Link the CSS like this (NOT a plain href):
      <link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
- Links between pages: use {{ url_for('<route_name>') }}
      Log in       -> {{ url_for('login') }}
      Register     -> {{ url_for('register') }}
      Movie X      -> {{ url_for('movie_detail', movie_id=m.id) }}
      Book movie X -> {{ url_for('booking', movie_id=m.id) }}
- Data you can use inside the templates:
      index.html         -> movies            (list of {id,title,price,duration})
      movie_detail.html  -> movie             (one movie dict)
      booking.html       -> movie, food       (food = list of {id,name,price})
      my_bookings.html   -> bookings          (list)
      manage_movies.html -> movies
      manage_food.html   -> food

DATABASE CONTRACT (Amigo BD) — expected in model.py
---------------------------------------------------
Classes (SQLAlchemy):
    Movie    (id, title, price, duration, description)
    Showtime (id, movie_id, start_time, room)
    Food     (id, name, price)
    User     (id, name, email, password_hash, is_admin)
    Booking  (id, user_id, showtime_id, seats, created_at)

Functions I will call from mainpage.py:
    get_movies()                               -> list[Movie]
    get_movie(id)                              -> Movie | None
    get_showtimes(movie_id)                    -> list[Showtime]
    get_food_catalog()                         -> list[Food]
    create_user(name, email, password)         -> User
    authenticate(email, password)              -> User | None
    create_booking(user_id, showtime_id,
                   seats, food_items)          -> Booking
    get_bookings(user_id)                      -> list[Booking]
    (admin) add_movie / edit_movie / delete_movie
    (admin) add_food   / edit_food   / delete_food
    (admin) add_showtime / edit_showtime / delete_showtime

HOW TO RUN
----------

    python mainpage.py
    open http://127.0.0.1:5000
